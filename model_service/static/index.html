    แหล่งข้อมูล

    • ดัชนีราคาผู้บริโภค ทั้งประเทศ 5 ภาค และ 76 จังหวัด (สนค. ไม่เผยแพร่ดัชนีของกรุงเทพฯ แยกเดี่ยว จึงใช้ดัชนี "กรุงเทพฯ และปริมณฑล" แทน รวมเป็น 77) — สำนักงานนโยบายและยุทธศาสตร์การค้า (สนค.) TPSO Open API
    • ราคาขายปลีกน้ำมันรถรายวัน (ดีเซล แก๊สโซฮอล์ 95/91/E20 กรุงเทพฯ ตั้งแต่ 2565) — Web Service ราคาน้ำมันของ ปตท. (PTT OilPrice)
    • ราคาขายปลีกรายวัน 283 สินค้า — กรมการค้าภายใน ดึงด้วย web scraping จากหน้าค้นหาราคา MOC Open Data (สำรองด้วย API)
    • ค่าจ้างขั้นต่ำ — สำนักงานปลัดกระทรวงแรงงาน (data.go.th) และประกาศคณะกรรมการค่าจ้าง ฉบับที่ 9, 11–14 (mol.go.th)
    • ราคาสินค้าปศุสัตว์หน้าฟาร์ม — กรมปศุสัตว์ (data.go.th)
    • ขอบเขตจังหวัด — OpenGISData-Thailand (ย่อจุดให้เล็กลง)
